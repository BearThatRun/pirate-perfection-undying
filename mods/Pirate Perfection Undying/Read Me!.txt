Pirate Perfection Undying v0.01 Unique Edition - x64 port for PAYDAY 2 (Diesel 3.0, 64-bit)
Port by BearThatRun (AI-assisted). Based on Pirate Perfection Reborn Trainer! V.I.P. Edition v2.0.0
by Baddog-11 and the Pirate Perfection Developer Crew. Edited with permission.

-- Requirements :
	- PAYDAY 2 64-bit (update 247 or newer)
	- SuperBLT 64-bit  (https://modworkshop.net/mod/58342)
	- BeardLib 5.1+    (https://modworkshop.net/mod/14924)

-- Installation :
	Copy the "Pirate Perfection Undying" folder into PAYDAY 2\mods\
	The file PAYDAY 2\mods\Pirate Perfection Undying\MOD.txt must exist (not one folder deeper).
	Do NOT copy an old 32-bit WSOCK32.dll, IPHLPAPI.dll or mods\base folder into your game.
	Settings: press F2 in game, or edit Trainer/config.lua. Key bindings: Trainer/keyconfig.lua.

-- Controls :
	-- These Keybinds Work Both Main-Menu & In-Game

		F1 : Help Menu
		F2 : Configuration Menu
		F3 : Main Pre-Game Menu / Character Menu
		F4 : Job Menu / Stealth Menu

		Page UP : Tools Menu
		Page Down : Music Menu
		Home : Normalizer Menu

		Delete : User Self-made Script (Depends on your Script)

	-- These Keybinds Work Only In-Game

		F6 : Interaction Menu
		F7 : Mission Menu
		F8 : Inventory Menu
		F9 : Equipment Menu
		F10 : Weapons Menu
		F11 : Mod Menu
		F12 : Spawn Menu

		Insert = Carry Stacker Control (Enable; Push/pop bag)(frequently tap it in order to drop all stored bags)
		End = Instant Win

		X : X-Ray Vision
		Z : Replenish

		5 : Equipment spawn menu
		4 : Quick Spawn selected equipment

		Middle Mouse Button : teleport
		Extra Mouse Button 1 : Slow Motion

-- Mods control :
	Superman mod:	Page Up - Fly up.
					Page Down - Fly down.

	Driver mod:		arrow left/right/up/down - Move left/right/up/down.


-- Changes from the original v2.0.0 :
	- Packaged for SuperBLT 64-bit, BeardLib is required and lists the mod in its mod manager
	- Removed: DLC unlocker, paid skin unlocks, anticheat bypass, mod hiding,
	  "not modded" lobby, name spoof, loot card spoof, troll menu (F5), stealth_v2
	- Removed: first-launch greeting, main-menu version text, scrolling banner, RSS feed,
	  update checker, announcements, donation stock ticker, loading-screen tip,
	  and all links to the old Pirate Perfection forum / site / Discord / Steam group
	- Trainer menus work on ultrawide and other non-16:9 screens
	- No more cmd.exe / hard-coded paths; several old bugs fixed
	- The full original changelog and every change are in the git history
