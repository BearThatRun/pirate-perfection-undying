Pirate Perfection Undying v0.01 Unique Edition - x64 port for PAYDAY 2 (Diesel 3.0, 64-bit)
x64 port by BearThatRun. Based on Pirate Perfection Reborn Trainer! V.I.P. Edition v2.0.0
by Baddog-11 and the Pirate Perfection Developer Crew. All credit for the original trainer is theirs.

-- Requirements :
	- PAYDAY 2 64-bit (update 247 or newer)
	- SuperBLT 64-bit  (https://modworkshop.net/mod/58342)
	- BeardLib 5.1+    (https://modworkshop.net/mod/14924)

-- Installation :
	Copy the "Pirate Perfection Undying" folder into PAYDAY 2\mods\
	The file PAYDAY 2\mods\Pirate Perfection Undying\MOD.txt must exist (not one folder deeper).
	Do NOT copy an old 32-bit WSOCK32.dll, IPHLPAPI.dll or mods\base folder into your game.
	Settings: press F2 in game, or edit Trainer/config.lua. Key bindings: Trainer/keyconfig.lua.

-- Controls :
	-- These keys work both in the main menu and in game

		F1 : Help Menu
		F2 : Configuration Menu
		F3 : Main Pre-Game Menu / Character Menu
		F4 : Job Menu / Stealth Menu

		Page Up : Tools Menu
		Page Down : Music Menu
		Home : Normalizer Menu

		Delete : User Self-made Script (depends on your script)

	-- These keys work only in game

		F5 : Troll Menu (yourself and AI only)
		F6 : Interaction Menu
		F7 : Inventory Menu
		F8 : Equipment Menu
		F10 : Mission Menu
		F11 : Mod Menu
		F12 : Spawn Menu
		(F9 is left free for the game's debug menu)

		End : Instant Win

	-- Keys you set yourself (SuperBLT: Options > Mod Keybinds)

		For example: Fly, Fly Up, Fly Down, God Mode, Aimbot, X-Ray Vision, Replenish, Slow Motion,
		Teleport To Crosshair / To Bullet, Carry Stacker, equipment spawning,
		grenade throwing and quick menus (Money, Skills, Music, Change Equipment).
		None of these have a default key.

-- Mods control :
	Driver and Helicopter mods: arrow keys move left/right/up/down.

-- Changes from the original v2.0.0 :
	- Packaged for SuperBLT 64-bit, BeardLib is required and lists the mod in its mod manager
	- Removed: DLC unlocker, paid skin unlocks, anticheat bypass, mod hiding,
	  "not modded" lobby, name spoof, loot card spoof, stealth_v2, fake stats
	  (unlock all achievements), and anything that acts against other human players
	- The F5 Troll menu is back, but it only works on yourself and on AI
	- Removed: first-launch greeting, main-menu version text, scrolling banner, RSS feed,
	  update checker, announcements, donation stock ticker, loading-screen tip,
	  and all links to the old Pirate Perfection forum / site / Discord / Steam group
	- Trainer menus work on ultrawide and other non-16:9 screens
	- No more cmd.exe / hard-coded paths; many old bugs and crashes fixed
	- Language files fixed so they load; English is used for any missing string
	- Every change is in the git history
